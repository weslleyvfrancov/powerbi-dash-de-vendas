# Relatório de Vendas | Projeto de Power BI

## Sobre o projeto

Este projeto foi desenvolvido como parte da formação **Power BI Analyst — DIO / Santander**, com o objetivo de aplicar conceitos de visualização de dados, construção de relatórios interativos e análise de indicadores de vendas e rentabilidade.

O relatório utiliza uma base de dados de amostra disponibilizada durante a formação e apresenta diferentes perspectivas para explorar o desempenho comercial, a distribuição geográfica das vendas e a contribuição dos segmentos para o lucro.

## Objetivos

- Desenvolver relatórios interativos utilizando o Microsoft Power BI.
- Aplicar conceitos de análise e visualização de dados.
- Explorar indicadores de vendas, unidades comercializadas e lucro.
- Analisar o desempenho por país e segmento.
- Organizar informações para facilitar a interpretação dos resultados.

## Visões do relatório

O projeto é composto por três páginas:

### Página 1 — Relatório de vendas
Reprodução da primeira página desenvolvida durante a formação, utilizando a base de dados de referência.

### Página 2 — Análise complementar
Reprodução da segunda página do curso, com continuidade da aplicação dos conceitos apresentados nas aulas.

### Página 3 — Análise geográfica e rentabilidade
Página desenvolvida como parte do desafio prático, contendo:

- **Vendas e unidades vendidas por país:** análise geográfica dos valores comercializados e das unidades vendidas.
- **Lucro por país:** visualização da distribuição geográfica do resultado financeiro.
- **Lucro por segmento:** gráfico de pizza para analisar a participação dos segmentos no lucro total.

## Ferramentas e tecnologias

- **Microsoft Power BI Desktop:** desenvolvimento e construção dos visuais.
- **Power BI Service:** publicação do relatório, quando disponível.
- **GitHub:** versionamento e documentação do projeto.

## Arquivos do projeto

- `PBIX`: arquivo-fonte do relatório Power BI, permitindo consultar sua estrutura e seus visuais.
- `PDF`: versão exportada do relatório para visualização e compartilhamento.

Os nomes dos arquivos podem variar conforme a organização adotada no repositório.
